# Breaking City

A browser-based 3D open-world game by **Breaking School** and **Breaking Biology**.
Drive around a Vice-City-style Dhaka, study real lessons to earn Taka, and spend it.

- Project rules for Claude: `CLAUDE.md`
- Build sessions: `docs/SESSIONS.md`
- How to add lessons, questions and posters: `docs/CONTENT_GUIDE.md`
- What was done so far: `docs/CHANGELOG.md`
- What the game is right now: `docs/GAME_SPEC.md`
- How the code is organised (for developers / Claude): `docs/HANDOFF.md`

Run locally: `python3 -m http.server 8000` in this folder, then open `http://localhost:8000/?debug=1`.

Play (after GitHub Pages is on): `https://breakersofficial01-cmd.github.io/shoumik--breaking--city/`
